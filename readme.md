GPU programming course material
===

The script `compile.sh` should compile the presentations by transforming `xx/y.md` to `xx/out/y.pdf` and `y.html` (if `y.md` has marp header).

In the `xx` dirs there is a ninja build that compiles the code into the `build` subdirectory. See the lab material in `01` on howto install ninja and the environment.
